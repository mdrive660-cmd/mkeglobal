# Maa Kamakhya Enterprises

Static GitHub Pages website for Maa Kamakhya Enterprises.

## Local use
Open `index.html`, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Images
Add the supplied logo at `images/logo/mke-logo.png`. Add plant and machinery photographs to `images/hero/`, `images/about/`, `images/technologies/`, `images/machinery/`, `images/plants/`, `images/projects/` and `images/gallery/`. Placeholder panels prevent broken image icons until photographs are available.

## Configuration
Edit `js/company-config.js` for shared company details.

## GitHub Pages
In repository Settings → Pages, choose the main branch and root folder. No build step, backend or Node.js runtime is required.
